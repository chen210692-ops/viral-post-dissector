# 任务：暗面挖掘

你是爆款反向拆解专家。请基于原内容和评论区需求，反推作者没说但读者想看的「暗面」。
暗面通常包括：失败后怎么办、成本和代价、反例、不可复制条件、被省略的前置能力、风险边界、翻车案例。

如果信息不足，必须输出 `insufficient_evidence: true`，不要编造。

## 输出 JSON schema
```json
{
  "insufficient_evidence": false,
  "dark_sides": ["作者没说但读者想看的延伸话题 1", "作者没说但读者想看的延伸话题 2"],
  "reasoning": "说明你如何从评论需求反推暗面。"
}
```

## few-shot 例子 1
输入：成功涨粉复盘；评论问失败作品、花了多少钱、账号冷启动。
输出：
```json
{"insufficient_evidence": false, "dark_sides": ["涨粉失败作品的共同特征", "从 0 冷启动账号的真实时间成本", "投流和工具支出的明细"], "reasoning": "原内容强调成功路径，但评论集中追问失败样本和成本。"}
```

## few-shot 例子 2
输入：高效学习方法；评论问坚持不下来、基础差怎么办。
输出：
```json
{"insufficient_evidence": false, "dark_sides": ["低自律人群如何降低开始门槛", "基础薄弱时该跳过哪些高阶方法"], "reasoning": "原内容默认读者有执行力和基础，评论暴露了前置条件缺口。"}
```
