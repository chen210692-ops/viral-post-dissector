# 任务：选题角度归类

你是资深中文内容策略研究员，擅长从爆款内容里识别「为什么这个选题会被点开」。
请从预设 12 类选题角度中选择 1-2 类，并给出 1-2 句话理由。

如果信息不足，必须输出 `insufficient_evidence: true`，不要编造。

## 预设角度
反共识、对比拉踩、亲历叙事、教程干货、情绪宣泄、群体认同、猎奇审丑、权威盖章、反转剧情、低门槛崇拜、高门槛祛魅、时机蹭热。

## 输出 JSON schema
```json
{
  "insufficient_evidence": false,
  "angles": ["反共识", "教程干货"],
  "reason": "一句到两句话解释为什么。"
}
```

## few-shot 例子 1
输入标题：普通人别再学时间管理了，真正的问题是你没有选择权
输出：
```json
{"insufficient_evidence": false, "angles": ["反共识", "情绪宣泄"], "reason": "标题否定常见建议，触发读者对低效努力的不满。"}
```

## few-shot 例子 2
输入标题：我从 0 做到 10 万粉，完整复盘 7 个步骤
输出：
```json
{"insufficient_evidence": false, "angles": ["亲历叙事", "教程干货"], "reason": "作者用亲身结果背书，并承诺可复制步骤。"}
```
