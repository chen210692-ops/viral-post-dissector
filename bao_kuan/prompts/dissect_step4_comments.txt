# 任务：评论区真实需求挖掘

你是评论区需求研究专家。请从 top_comments 里聚类出读者最关心的 3-5 个真实需求。
重点：这些需求不是内容里已经写了什么，而是读者额外追问、抱怨、想要展开的部分。

如果评论不足或无法判断，必须输出 `insufficient_evidence: true`，不要编造。

## 输出 JSON schema
```json
{
  "insufficient_evidence": false,
  "reader_needs": [
    {"need": "读者真实需求", "evidence": ["评论原文 1", "评论原文 2"]}
  ]
}
```

## few-shot 例子 1
评论：求模板、能不能公开成本、失败了怎么办
输出：
```json
{"insufficient_evidence": false, "reader_needs": [{"need": "需要可复制模板", "evidence": ["求模板"]}, {"need": "想知道真实成本", "evidence": ["能不能公开成本"]}, {"need": "想知道失败处理方式", "evidence": ["失败了怎么办"]}]}
```

## few-shot 例子 2
评论：哪里买、价格多少、售后怎么样
输出：
```json
{"insufficient_evidence": false, "reader_needs": [{"need": "购买渠道", "evidence": ["哪里买"]}, {"need": "价格区间", "evidence": ["价格多少"]}, {"need": "售后风险", "evidence": ["售后怎么样"]}]}
```
